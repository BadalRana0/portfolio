How to add your work:
Upload your image/video files to your GitHub repo, then copy each file's raw URL (format: https://raw.githubusercontent.com/USERNAME/REPO/main/path/file.jpg).

For an image, replace a placeholder block with:
<div class="g-item"><img class="g-media" src="YOUR_URL_HERE" alt=""></div>

For a video, use:
<div class="g-item"><video class="g-media" autoplay muted loop playsinline src="YOUR_URL_HERE"></video></div>

Add as many g-item blocks as you need — the grid expands automatically.
